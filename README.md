# 上班鼓励器 · Work Encourager

一个 iOS 液态玻璃风格的桌面悬浮小工具，实时显示你上班赚了多少钱。

> 每天上班有多难熬？盯着数字往上跳，是打工人唯一的精神食粮。

![screenshot](screenshot.png)

## 功能

### 核心
- **实时金额滚动**：毫秒级精度计算，金额像银行流水一样持续递增
- **三态状态**：未上班 / 上班中 / 已下班，自动切换
- **赚钱速度**：显示元/秒，直观感受"一秒几厘"
- **下班倒计时**：距离下班还有多久

### 数据卡片
- 今日工时进度条（已工作 X / 总工时 Y 小时）
- 本月累计已赚（自动按工作日补算）
- 时薪
- 今日满勤可得
- 本月剩余工作日
- 距离发薪日还有几天

### 鼓励语
- 6 种风格自动轮换：奶茶小目标 / 打工人吐槽 / 美食诱惑 / 佛系治愈 / 暴富励志 / 摆烂躺平
- 点刷新按钮换一句
- 支持自定义鼓励语文案

### 交互
- 金币飘落动画 + 点击爆金币音效（Web Audio 合成，无需外部文件）
- 下班冲刺模式：距下班 10 分钟红光呼吸
- 下班庆祝彩蛋：状态切换时全屏金币雨
- 深浅色模式切换，自动记忆

### 设置
- 日薪 / 月薪切换（月薪自动除以计薪天数换算）
- 自定义每月计薪天数（默认 21.75）
- 午休时间扣除（午休时段不计入工时）
- 自定义休息日（双休 / 单休 / 随便哪天休都能选）
- 发薪日设置
- 所有数据卡片支持行内点击编辑覆盖

### 极简模式
- 双击空白区域切换极简模式
- 窗口缩成屏幕右上角小条，只显示金额
- 点小条恢复全屏

## 使用方法

### 快速开始（推荐）

1. 下载全部文件到同一个文件夹
2. 双击 `一键启动.bat`，自动打开独立应用窗口（无地址栏，像原生应用）
3. 点右上角齿轮图标，填入你的日薪、工时、上班时间
4. 把窗口拖到桌面角落，该上班上班

### 普通浏览器打开

如果不想用 .bat，也可以直接双击 `上班鼓励器.html` 用浏览器打开，功能都一样，只是窗口有地址栏。

### 手动创建桌面快捷方式（Windows）

想要桌面图标、开机自启的话：

1. 右键 `一键启动.bat` → 发送到 → 桌面快捷方式
2. 右键桌面快捷方式 → 属性 → 更改图标，选一个你喜欢的图标

## 技术栈

- 单文件 HTML，零依赖，无需联网
- 原生 JavaScript，CSS 液态玻璃效果
- localStorage 持久化配置
- Web Audio API 合成音效
- requestAnimationFrame 驱动金额滚动
